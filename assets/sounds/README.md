# Sound Effects for SNU SQL-Quest

This folder should contain the sound effects for the game. Download free sound effects and place them here.

## Required Files

Place the following files in this directory:

- **success.wav** - Success/victory sound
- **error.wav** - Error/failure sound
- **ambient.mp3** - Background music (looping)
- **page-turn.wav** - Page turn/navigation sound

## Where to Download Free Sounds

### Recommended Sources (CC0 / Public Domain):

1. **Pixabay** - https://pixabay.com/sound-effects/
   - Free for commercial use
   - No attribution required
   - High-quality sounds

2. **Freesound** - https://freesound.org/
   - Creative Commons licensed
   - Large library
   - May require attribution (check license)

3. **Zapsplat** - https://www.zapsplat.com/
   - Free sound effects
   - Requires free account

### Suggested Search Terms:

- **success.wav**: "success", "victory", "achievement", "level up", "chime"
- **error.wav**: "error", "wrong", "buzz", "negative"
- **ambient.mp3**: "fantasy music", "medieval", "adventure", "mystical"
- **page-turn.wav**: "page turn", "whoosh", "swipe"

## File Format Notes

- **WAV files** (.wav) are preferred for short sound effects
- **MP3 files** (.mp3) are preferred for longer music tracks
- Make sure files are reasonably sized (< 5MB each)

## Optional

If you don't add sound files, the game will work fine without audio - it just won't play sounds.
