# Direct Links to Free Sound Effects

Here are direct links to free, high-quality sound effects that work perfectly with SNU SQL-Quest.

## Quick Download Guide

1. Click each link below
2. Download the sound file
3. Rename it to the required filename
4. Place it in the `assets/sounds/` folder

---

## Alternative Sources

If Pixabay links don't work or you want more options:

### Freesound.org
1. Go to https://freesound.org/
2. Search for the sound type (e.g., "magic success")
3. Filter by license: "Creative Commons 0" for no attribution needed
4. Download and rename

### OpenGameArt.org
- URL: https://opengameart.org/
- Great for game sound effects
- Check individual licenses

### Incompetech (Music)
- URL: https://incompetech.com/music/royalty-free/music.html
- Excellent for background music
- Requires attribution (add to credits)

## Testing Your Sounds

After adding the files:

1. Open `index.html` in a browser
2. Click the "Music: ON" button to test background music
3. Try a correct SQL query to hear the success sound
4. Try an incorrect query to hear the error sound
5. Click "Continue to Next Quest" to hear the page turn sound

---

**Tip**: If sounds don't play, check the browser console (F12) for errors and verify file paths.
